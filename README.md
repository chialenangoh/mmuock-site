# M'muock Fosimondi Community Ohio USA — Website (Next.js rebuild)

Rebuilt from the WordPress site (mmuockfosimondiohio.org) in October 2026 after the
WordPress/Elementor editor fault made the old site uneditable. Content is carried
over verbatim from the WordPress export of 2026-10-29; see REBUILD-INVENTORY.md
for the page-by-page inventory.

Stack mirrors the Christ Light Foundation site: Next.js 15 (App Router),
React 19, Tailwind CSS v4. Scripts: `npm run dev`, `npm run build`, `npm start`.
